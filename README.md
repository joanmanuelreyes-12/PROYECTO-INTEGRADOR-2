## Descripción del proyecto

El proyecto consiste en desarrollar un sistema para administrar los asientos de una sala de cine mediante una matriz.

El sistema permitirá visualizar los asientos, reservar asientos disponibles, liberar asientos ocupados y consultar la disponibilidad de la sala.

También permitirá obtener información sobre la cantidad de asientos ocupados, la cantidad de asientos disponibles y el porcentaje de ocupación.

El proyecto busca facilitar la administración de los asientos y reducir errores durante el proceso de reservación.

---

## Objetivo

Desarrollar un sistema que permita administrar los asientos de una sala de cine de forma organizada mediante el uso de una matriz.

El sistema deberá permitir realizar operaciones de reservación, liberación y consulta de los asientos.

---

## Estructura de datos

La estructura de datos principal del proyecto será una **matriz**.

La matriz representará los asientos de la sala mediante filas y columnas.

Cada posición de la matriz representará un asiento y almacenará su estado.

```text
0 = Disponible
1 = Ocupado
```

La matriz permitirá localizar, consultar y modificar el estado de cada asiento.

---

## Funcionalidades

El sistema tendrá las siguientes funcionalidades:

- Mostrar la matriz de asientos.
- Reservar un asiento.
- Liberar un asiento.
- Consultar la disponibilidad.
- Contar los asientos ocupados.
- Contar los asientos disponibles.
- Calcular el porcentaje de ocupación.
- Validar operaciones sobre los asientos.
